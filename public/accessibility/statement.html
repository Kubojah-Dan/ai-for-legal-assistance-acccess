Accessibility Statement WCAG 2.1 AA

Effective Date: July 1, 2024 (Aligned with Bharatiya Nyaya Sanhita 2024 implementation)

Commitment: NyayaMitra (न्यायमित्र) is dedicated to ensuring digital legal accessibility for every Indian citizen, including individuals with visual, motor, auditory, or cognitive disabilities, and users on low-end Android mobile devices.

1. Conformance Status

This web application conforms to Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. All user flows—including natural language intake, rights evaluation, document generation, and legal aid escalation—are tested and fully operable via screen readers and keyboard navigation alone.

2. Key Accessibility Features Implemented

  • Strict Semantic ARIA Markup: Tab navigation strictly implements role="tablist", role="tab", role="tabpanel", aria-selected, and aria-controls.
  • Explicit Form Labels: 100% of input controls and form fields feature explicit <label htmlFor="..."> linkages. No bare, disconnected inputs exist.
  • Live Region Screen Reader Announcements: Real-time legal analysis and AI responses use aria-live="polite" regions with role="status" so assistive tech announces incoming rights data without interrupting current focus.
  • Voice-First Intake (Web Speech API): Low-literacy and vernacular users can speak directly in Hindi or English using an accessible, high-contrast microphone button with clear active states.
  • Reduced Motion Support: Global styles respect @media (prefers-reduced-motion: reduce) by disabling animations for users sensitive to vestibular motion.
  • High Contrast Color Compliance: Color contrast ratios strictly exceed 4.5:1 for normal text and 3:1 for large text / interactive boundaries, conforming to @media (prefers-contrast: more).
  • Cognitive Clarity: Complex legal statutes are translated into Grade 6 plain language summaries alongside formal BNS/BNSS citations.
